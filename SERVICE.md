# AI-Assisted Python Repository Stabilisation Audit

Make an existing Python repository easier for a human or coding agent to run,
verify and continue developing.

## Good fit

This fixed-scope audit is for an independent developer or small team that
already has a Python repository and uses Codex, Claude Code, Cursor or a similar
coding assistant.

It is useful when:

- an assistant changes working behaviour outside the task;
- installation, test or build commands are unclear;
- generated changes break another workflow;
- project instructions are missing, stale or contradictory;
- large prompts consume context without a verifiable result; or
- an AI-generated project is difficult to hand over.

## Founding price and scope

Included:

- one existing Python repository;
- one primary local development environment;
- up to three core workflows;
- installation, run, test and build command checks;
- review of AGENTS.md, CLAUDE.md or equivalent instructions;
- the five highest-priority reliability risks;
- context-selection and token-efficiency recommendations;
- missing tests and acceptance checks;
- a prioritised 14-day improvement plan;
- one small example improvement; and
- one written or recorded handover.

## Process

1. Confirm the repeated failure, repository size, access method and desired
   result.
2. Agree on privacy, access and scope boundaries.
3. Reproduce current installation, run, test and build behaviour.
4. Separate existing product defects from repository-workflow defects.
5. Prioritise findings with evidence and acceptance checks.
6. Prepare one bounded example improvement.
7. Deliver the report, evidence and next-step plan.

Each finding uses:

> Problem -> Evidence -> Impact -> Recommendation -> Priority ->
> Acceptance Check

## What the client provides

- a repository or sanitised copy they are authorised to share;
- Python and operating-system versions;
- current installation, run, test and build instructions;
- the coding assistant used;
- two or three recent repeated failure examples; and
- the desired audit result.

Do not send live API keys, production passwords, private customer records or
unredacted production data.

## Not included

- new product features;
- a full-repository refactor;
- repair of every existing defect or failing test;
- production deployment or server administration;
- access to live systems or customer accounts;
- penetration testing, compliance certification or legal review;
- support beyond the agreed handover; or
- a promise that future coding-agent changes will be error-free.

If the repository cannot be installed or run, the audit documents the blocker
and the shortest recovery path within the agreed timebox. Implementation beyond
the example change is scoped and priced separately.
