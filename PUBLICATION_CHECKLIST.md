# Publication Checklist

This package is ready for local review, not automatic publication.

## Content review

- [ ] Read every Markdown file.
- [ ] Inspect each SVG at full resolution.
- [ ] Confirm all sample material is marked fictional.
- [ ] Confirm every result matches the dated evidence.
- [ ] Confirm the case study discusses engineering, not investment outcomes.
- [ ] Confirm contact links open the intended public LinkedIn pages.

## Privacy and claim review

- [ ] Search for usernames, local paths, credentials and private URLs.
- [ ] Confirm no private source code or customer material was copied.
- [ ] Confirm there are no invented customers, revenue or testimonials.
- [ ] Confirm there are no unsupported efficiency or token-saving figures.
- [ ] Confirm the audit is not described as formal security certification.

## Repository decisions

- [ ] Approve the exact files for publication.
- [ ] Choose repository ownership.
- [ ] Choose a licence or deliberately publish without one.
- [ ] Create a new public repository only after approval.
- [ ] Push the reviewed local commit.
- [ ] Enable only the GitHub features actually needed.

## Launch

- [ ] Add the public repository to LinkedIn Featured.
- [ ] Add the link to the LinkedIn service page if appropriate.
- [ ] Use the link only in relevant, personalised conversations.
- [ ] Record enquiries and outcomes in the prospect tracker.
